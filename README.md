# ia-odyssee-humaine.github.io/github.io

# Illustrations sonores

Page compagnon du livre *IA : une odyssée humaine — Rester vivant à l'ère des machines*, de Sandy Razafitrimo.

Quatorze QR codes imprimés dans le livre pointent vers ce site. Chaque code ouvre une page de redirection qui renvoie vers la vidéo officielle du morceau.

## Pourquoi une redirection

Les adresses YouTube changent, les vidéos disparaissent. Les QR codes imprimés, eux, ne changent plus. La page intermédiaire permet de remplacer un lien mort sans que les exemplaires vendus deviennent inutilisables.

## Mettre à jour un lien

Ouvrir `nom-du-morceau/index.html`, remplacer l'adresse qui suit `url=` dans la balise `meta http-equiv="refresh"`, valider. Le changement est en ligne en une minute.

## Ce que ce dépôt ne contient pas

Aucun fichier audio ni vidéo, aucune parole, aucune pochette. Uniquement du texte et des liens vers les chaînes officielles des artistes et de leurs labels.
